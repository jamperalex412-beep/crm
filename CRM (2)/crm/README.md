# CRM — учёт клиентов

PHP 8.1+ и MariaDB/MySQL, без фреймворков и Composer.

## Роли

| Роль | Что видит | Что может |
|---|---|---|
| **Администратор** | всё | создаёт сотрудников (логин/пароль), роли и команды, статусы, журнал действий, экспорт, импорт, удаление |
| **Шифт** | всех клиентов | переназначает любого клиента любому сотруднику, экспорт, импорт, структура команд |
| **Тимлидер** | своих клиентов и клиентов своей команды | добавляет свободных менеджеров в команду, передаёт им лидов |
| **Менеджер** | только своих клиентов | работает с карточкой, статусами, перезвонами и комментариями |

## Возможности
- **Клиенты:** ГЕО по номеру (флаг и страна), копирование номера, ID и email одной кнопкой, звонок, WhatsApp, Telegram, Viber, email. Фильтры (страна, ответственный, перезвоны, даты), сортировка, массовые действия, защита от дублей по номеру.
- **Статусы:** цветные категории. Меняются кликом прямо в списке. Настраиваются в разделе «Статусы».
- **Перезвоны:** дата и время в карточке (кнопки «+1 ч» и «Завтра 10:00»), раздел «Перезвоны» (просрочено / сегодня / завтра / неделя), кнопка «✓ Выполнен».
- **Уведомления:** колокольчик показывает наступившие перезвоны и сообщения «вам передали клиента». Всплывающее и браузерное уведомление, когда подходит время звонка (проверка раз в минуту).
- **Дашборд:** плитки, новые клиенты по дням, статусы, страны, активность сотрудников за период. Тимлидер видит свою команду, менеджер — себя.
- **Экспорт:** CSV для Excel по текущим фильтрам списка. Только для администратора и шифта, каждая выгрузка пишется в журнал.
- **Журнал действий** (администратор): входы и неудачные попытки, просмотры карточек, изменения, передачи, статусы, экспорт, удаление, действия с сотрудниками, IP. Хранится 180 дней.
- **Импорт** из CSV с раздачей лидов поровну.
- **Безопасность:** пароли в bcrypt, CSRF-защита, защита от перебора паролей, роли проверяются на сервере.

## Установка на Proxmox (Франкфурт) — автоматически

### 1. Создать новый контейнер
В Proxmox: **Create CT**
- Template: `ubuntu-24.04-standard` (скачать: local → CT Templates → Templates);
- 2 ядра, 2048 МБ RAM, диск 20 ГБ;
- Network: IP из пула Velia (статический), шлюз — как у других контейнеров;
- **Unprivileged container** — да.

Ставьте CRM в **отдельный** контейнер, а не в 103 (там бот анкет).

### 2. Домен
У регистратора домена создайте A-запись, например `crm.вашдомен.com`, на IP контейнера.

### 3. Залить архив и запустить
Скопируйте `crm.zip` в контейнер (WinSCP/FileZilla по SFTP или `pct push <ID> crm.zip /root/crm.zip` с хоста), затем в консоли контейнера:
```bash
apt update && apt install -y unzip
cd /root && unzip crm.zip && cd crm
bash install.sh crm.вашдомен.com admin@вашдомен.com
```
Скрипт спросит имя, логин и пароль главного администратора, затем сам:
- поставит nginx, PHP и MariaDB;
- создаст базу со случайным паролем;
- установит CRM в `/var/www/crm` и удалит установщик;
- получит бесплатный HTTPS-сертификат (Let's Encrypt, продлевается сам);
- включит ежедневный бэкап базы в `/var/backups/crm` (хранится 14 дней);
- сохранит все пароли в `/root/crm-credentials.txt` (доступ только root).

**Пустить в CRM только с ваших IP** (офис, WireGuard):
```bash
ALLOW_IPS="1.2.3.4 10.8.0.0/24" bash install.sh crm.вашдомен.com admin@вашдомен.com
```

**Без домена (для теста):** `bash install.sh` — CRM откроется по `http://IP-контейнера`.

### Обновление
Распакуйте новую версию поверх папки `/root/crm` и запустите:
```bash
bash install.sh --update
```
Файлы заменятся, база и настройки останутся, перед обновлением делается бэкап.

### Восстановление из бэкапа
```bash
gunzip < /var/backups/crm/crm-ДАТА.sql.gz | mysql crm
```

## Установка на cPanel / Namecheap (вручную)
Создать базу и пользователя MySQL в cPanel → залить файлы в папку поддомена → открыть `/install.php` → удалить `install.php` и `install_cli.php`. `.htaccess` уже закрывает служебные файлы.
